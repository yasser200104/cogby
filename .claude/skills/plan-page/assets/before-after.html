The row

SEC-9: pin outbound traffic through an egress proxy
Before, the ordinary way 237 words

SEC-9 is step 2 of the security architecture and covers egress pinning for provider spawns. Today every headless provider turn runs inside an OS namespace built by the sandbox module, which empties the signing key directory, removes the dotenv file from the filesystem view and exposes only the secrets that the lane's reach grants, while the harness trees are mounted read-only and ungranted token caches do not exist at all. That containment is real but it is filesystem and environment scoped only: the network namespace is unrestricted, so a boxed turn can still open a socket to any host on the internet, which means that an injected instruction in content the model reads could still exfiltrate whatever that turn legitimately holds in memory, since the floor rules operate on tool patterns rather than on destinations. The proposed work introduces a local proxy that terminates all outbound HTTP from inside the namespace and refuses any host not present in an allowlist derived from the same reach grammar the permission policy already uses, which would close the gap. It is estimated at roughly two weeks of work, it has a hard dependency on the sandbox backend being installed since a turn that runs unboxed has no namespace to attach the proxy to, and containment is currently optional by default on installs with no backend, so on those boxes this buys nothing until the containment policy is moved to required.

After, at format 139 words
Egress (outbound traffic): every connection a job opens to the outside while it runs. Pinning it means naming the hosts it may reach, and refusing the rest.

The box already closes three walls. SEC-9 closes the fourth, and reuses a list that exists.

The rule

Few words is not less detail

The failure this example exists to prevent is the opposite of verbosity: a session reads "fewest words", summarizes, and hands over a page that is poorer than the prose it replaced. Nothing above was summarized. Every number, every dependency and every caveat from the left survived into the right. What changed is what carries them: a diagram, a table, a definition box, four cards.

A page that is dense in information and poor in sentences is the target. If a paragraph says what the diagram already shows, the paragraph goes, not the diagram.
